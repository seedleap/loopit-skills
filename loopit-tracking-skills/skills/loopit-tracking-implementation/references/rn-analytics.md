# RN、Native 与 H5 采集核查

实现埋点时沿实际链路回读动作入口、同步快照、预处理、字段转换、具体消费者、各发送器和最终 payload。路径必须按目标仓库当前 checkout 重新核实，不猜替代实现。

优先检查以下责任边界：

| owner | 核对内容 |
| --- | --- |
| 业务动作 | 点击、可见、提交、请求和结果终态的真实时机 |
| 公共 analytics client | 标准事件入口、身份、环境和投递目标 |
| 预处理与映射 | canonical 字段、缩写、序列化和 tags/raw 处理 |
| Native 或 Bridge | H5 到宿主的字段和确认边界 |
| 投递客户端 | 请求构造、重试、持久化和目标服务 |

`track()` 调用存在只能证明源码有调用，不能证明最终出网、TEA 收件或业务结果成立。账号、作品、订单和页面来源需要按实际链路分别验证。
