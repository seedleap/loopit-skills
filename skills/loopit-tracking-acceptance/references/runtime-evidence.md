# 运行态埋点证据

按以下顺序保存证据：

```text
场景输入
  -> 用户可见行为
  -> 客户端事件调用
  -> 最终 payload
  -> TEA 收件明细
  -> 权威业务终态
```

每层分别记录版本、环境、时间、事件 ID、账号或业务对象、关键属性、状态和证据位置。截图没有露出字段时写“未取证”，不要据画面缺失推断为空。

| 证据层 | 可证明内容 | 不能单独证明 |
| --- | --- | --- |
| 源码 | 触发和字段来源的静态实现 | 已部署或线上收件 |
| 客户端 payload | 本次运行发出的字段 | TEA 已落库或业务成功 |
| TEA 明细 | 指定筛选下的收件和字段 | 权威业务终态 |
| 服务端终态 | 交付、入账或业务成功 | 客户端是否正确展示 |
